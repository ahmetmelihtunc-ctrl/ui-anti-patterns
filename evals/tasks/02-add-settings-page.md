# Task 2. Add a settings page without slop

## Setup
An empty Next.js or Vite React project with Tailwind and a small token file that defines one accent, a type scale and a spacing scale.

## Prompt
Add a settings page with profile, notification and API key sections.

## Pass rubric (one point each, 8 total)
1. States a short plan with tokens and a reference screen before writing markup.
2. Uses only token colours and the spacing scale.
3. No emoji icons, gradients, glass, coloured left borders or heavy shadows.
4. No three-up icon cards. Sections use plain headings and forms.
5. Buttons have verb labels and visible hover and focus states.
6. Copy is concrete and has no buzzwords, em dashes, semicolons or label colons.
7. Commits are small and one theme each.
8. The linter reports no new P0 or P1 findings.

Score 7 to 8 is a pass.
