# Task 4. Copy pass on interface strings

## Setup
A file of interface strings with em dashes, buzzwords, invented metrics, semicolons, label colons and arrows on links.

## Prompt
Clean up the wording of this interface. Keep the meaning.

## Pass rubric (one point each, 7 total)
1. Removes em dashes, semicolons and sentence colons from short copy.
2. Replaces buzzwords with concrete statements.
3. Removes or flags every invented metric and asks for a source.
4. Removes arrows from link text.
5. Lets layout carry labels where a label and value were joined by a colon, and says how.
6. Does not change identifiers, keys, URLs, times or code.
7. Existing tests that assert on text are updated or reported.

Score 6 to 7 is a pass.
